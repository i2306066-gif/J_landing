# 보약남 (J) 랜딩페이지

보험 약관 읽어주는 남자, **정재원 설계사**의 인스타그램 광고용 랜딩페이지입니다.

## 개요

- **브랜드**: 보약남 (보험 약관 읽어주는 남자)
- **설계사**: 정재원 (토스인슈어런스 소속)
- **목적**: 인스타그램 광고 → 카카오톡·전화 상담 연결
- **구조**: 단일 `index.html` (이미지·폰트 base64 임베드, 외부 의존성 없음)

## 디자인

- 폰트: Toss Product Sans (Heavy / Bold / Medium 서브셋 임베드)
- 컬러 컨셉: 토스 블루 기반 핀테크 인포그래픽 스타일
- 모바일 우선 (480px 기준)

## 페이지 구성

히어로 → 공감 → 관점전환 → 3가지 핵심 보장(실손·항암·간병인) → 연령별 추천 → 정재원 설계사 소개 → 후기 → CTA(카카오톡·전화) → 필수 안내사항

## 배포

Vercel에 연결 시 `main` 브랜치 push → 자동 재배포.
정적 사이트이므로 별도 빌드 과정 없이 `index.html`만 서빙됩니다.

## ⚠️ 배포 전 필수 확인

- [ ] **준법감시인 심의필 번호** 기입 (현재 플레이스홀더 상태 — 심의 없이 배포 금지)
- [ ] 카카오톡 채널 링크 / 전화번호가 정재원 설계사 정보와 일치하는지 확인
- [ ] 후기 문구는 예시 → 실제 상담 후기로 교체 (심의 시 후기 사용 가능 여부 확인)
